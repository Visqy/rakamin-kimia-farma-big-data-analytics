# Kimia Farma Big Data Analytics

A business performance analytics case study from **Rakamin × Kimia Farma**, using transaction data from 2020–2023.

## Tech Stack

- Google BigQuery
- SQL
- Google Looker Studio

## Project Overview

This project focuses on analyzing sales performance, estimated profit, regional performance, product contributions, and branch ratings through an interactive dashboard.
